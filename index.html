shape-puzzle-captcha

Everything goes into the square hole!

The component itself only provides the visual aspects of a 3D shape puzzle and a captcha-like interface. This can be spoofed and is not meant to protect you from attacks. For actually secure captchas, a backend is required. To integrate this component with a backend, listen for the solved event and verify other client info on the backend.

Tweak with the colors and reset the captcha to see how it works. The state will be updated in real-time as you interact with the captcha. Try to solve the puzzle!

Quick Start

Using a package manager

  • Install the package from npm: 
    npm install @r3dacted42/shape-puzzle-captcha
  • Register the component: 
    import '@r3dacted42/shape-puzzle-captcha';
  • Add the component to your markup:
  • Listen for events:
    The event key is customizable via the event-key attribute, but defaults to "shapepuzzlecaptcha". 
    window.addEventListener('captcha:solved', (e) => { ... });
window.addEventListener('captcha:reset', (e) => { ... });
window.addEventListener('captcha:failed', (e) => { ... });
    For the complete list of events and methods, check out the repository README.

Using a CDN

  • Add the importmap and component script to your HTML: 
    <script type="importmap">
  {
    "imports": {
      "lit": "https://cdn.jsdelivr.net/gh/lit/dist@3/core/lit-core.min.js",
      "three": "https://unpkg.com/three@0.183.0/build/three.module.js",
      "three-bvh-csg": "https://unpkg.com/three-bvh-csg@0.0.18/build/index.module.js",
      "three-mesh-bvh": "https://unpkg.com/three-mesh-bvh@0.9.9/build/index.module.js"
    }
  }
</script>
<script
  type="module"
  src="https://unpkg.com/@r3dacted42/shape-puzzle-captcha/dist/shape-puzzle-captcha.js"
</script>
  • Then you can add the component to your markup as described in the previous section.
